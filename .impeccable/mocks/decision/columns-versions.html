The Columns fold: four ideas

Option A's page, with Columns open for a file the app does not recognise (it widens past the narrow column while open). Same Argenta-style file in all four. A recognised KBC or Belfius file never opens this section.

A · We guess, you check

Every column is guessed from the header names and the values underneath. You read a short list of statements and only look closely at the ones marked "check this". The file settings sit in one line.

B · Point at the column

The file itself is the form. Three questions, one at a time, and you answer by clicking a column header. Optional extras are tagged the same way, or skipped.

C · Read it back as a transaction

You never see a field list. One row is shown as a real transaction; anything that looks wrong is clicked and fixed. File settings only come up as a fix, such as "€8,412.00 looks too big".

D · Needed, smarter, file settings

The current form, sorted into three groups: 3 needed, 4 optional (each saying what it gives you), and the 6 file settings folded into one guessed line. The lowest build cost.
