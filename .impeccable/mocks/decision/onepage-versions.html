One page, top to bottom: three versions

Each shows the same page twice: while you import, and when it is done. Same September data throughout.

A · Folding receipt

One narrow column. Finished sections fold to a line; a section with nothing to ask skips itself; the overview opens in place at the bottom.

B · Fill-in sentence

Each file is one sentence the app fills in. Coloured words can be changed, dashed blanks are the only things it needs from you, and the overview continues the story.

C · Page and running total

Sections on the left, a dark summary on the right that totals what will happen, holds the Import button, and turns into the overview. Afterwards the left becomes the import history.
