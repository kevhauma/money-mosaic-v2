# TICKET-IMP-17 — Guess the columns, and let the user check the guess

- **Area:** Import
- **Released in:** _unreleased_
- **Type:** Feature
- **Traceability:** FR-IMP-* (column mapping); design round 2026-10-18 (`.impeccable/mocks/decision/reading-then-columns.html`, idea A "We guess, you check")

## User story

As someone importing an unfamiliar bank export, I want the app to guess which column is the date, the amount, the description and the rest, and show me what each would read as, so that mapping a file is a check rather than nine dropdowns.

## Description

A pure column guesser scores each header against every field, by header name (Dutch, French, English bank vocabulary) and by the shape of the values under it (dates, amounts, IBANs, the same IBAN on every row, long text). The **Columns** section lists the result as statements — "Amount ← Bedrag → −€84.12 · sure" — in two groups: what is needed and what makes rules and transfers smarter.

## Current situation (as-is)

- Nothing guesses columns. Without a matching bank preset, all nine fields start empty in [import-map-step.component.ts](../../../src/app/feature-import/components/import-map-step/import-map-step.component.ts) and are walked one per sub-step ([mapper-steps.ts](../../../src/app/feature-import/mapper-steps.ts), TICKET-IMP-09).
- Saving a mapping is a separate name field plus a "remember" checkbox at the end of the stepper.

## Desired result (to-be)

- `guessColumns(headers, rows, reading)` returns, per field, a column (or none) with `sure` / `check` / `missing`, the runner-up column when unsure, and single vs split (money in + money out) amount.
- The section's rows: field name, a select of the file's headers, what the first row reads as, and a sure / check-this / not-found marker. The amount row switches between one column and money in + money out.
- Optional fields carry a short reason ("finds transfers between your own accounts").
- "Remember these columns for files like this one", with a name defaulting from the file name, saves the mapping so the file type is recognised next time.
- **Looks right** is enabled once date, amount and description are mapped.
